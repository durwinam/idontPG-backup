# Security Policy

## Supported Versions

Security updates are currently provided for the latest release series of
idontPG-backup.

| Version | Supported          |
| ------- | ------------------ |
| 5.7.x   | :white_check_mark: |
| 5.6.x   | :x:                |
| 5.5.x   | :x:                |
| < 5.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in idontPG-backup, please report it
privately through our official Telegram contact:

**Telegram:** https://t.me/DuRnaziiAy

Please do not publicly disclose the vulnerability before it has been reviewed.

### Response Time

We aim to review and respond to security reports within a maximum of **8 hours**.

### If the Vulnerability Is Confirmed

If the reported vulnerability is confirmed:

- We will investigate and work on resolving the issue.
- Reported information will be kept confidential.
- Any confirmed loss or damage caused by the vulnerability will be compensated.

### If the Report Is Declined

If the report is determined not to be a valid security vulnerability:

- The report will be closed.
- No action or compensation will be provided.

Thank you for helping us keep idontPG-backup secure.
